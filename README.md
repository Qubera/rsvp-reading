# RSVP Reading

Кроссплатформенное приложение скоростного чтения (RSVP — Rapid Serial Visual Presentation)
для **iOS** и **Android** на Expo (React Native 0.86 + TypeScript strict).

Слова появляются по одному в фиксированной точке экрана. Опорная буква (ORP) всегда
в центре — глаза не двигаются, скорость чтения растёт. Все данные хранятся локально,
приложение работает офлайн.

## Запуск

```bash
npm install
npm start            # Expo dev-сервер (Expo Go на телефоне или эмулятор)
npm run android      # эмулятор/устройство Android
npm run ios          # симулятор iOS
```

Проверки:

```bash
npm run typecheck    # tsc --noEmit (strict)
npm test             # 49 юнит-тестов ядра (tsx scripts/run-tests.ts)
npm run export:web   # веб-сборка (использовалась для визуальной проверки UI)
```

## Возможности

- **RSVP-ридер**: точный timing-engine (unit-based расписание без дрейфа, RAF-такт),
  плавная работа на 100–1500 слов/мин; пауза после точек/запятых/абзацев, замедление
  длинных слов; ORP-подсветка опорной буквы; автопауза после абзаца.
- **Импорт**: TXT/MD (UTF-8 + фолбэк CP1251), PDF (свой парсер: ObjStm, FlateDecode,
  ToUnicode CMap), EPUB (fflate → OPF/spine → XHTML), веб-страница по URL, буфер обмена,
  ручной ввод; камера с архитектурой OCR (`src/services/ocr/OcrService.ts`, движок
  подключается без изменения остального кода).
- **Библиотека**: категории (Книги/Статьи/PDF/Другое), поиск, переименование, удаление
  с подтверждением, статусы «не начато / читается / завершено», прогресс.
- **Выбор диапазона**: весь текст, диапазон страниц (PDF — реальные страницы,
  остальные — синтетические ~230 слов), фрагмент (проценты от текста).
- **Статистика**: сессии чтения, всего слов, средняя/максимальная скорость, время,
  график по дням, фильтры Неделя/Месяц/Всё время.
- **Настройки**: скорость, 4 шрифта (Inter, Manrope, Literata, JetBrains Mono), размер,
  цвета текста/фона (5 пресетов), интервалы, пунктуационные паузы, тема Dark/Light/System,
  язык Русский/Қазақша/English, ежедневное напоминание (20:00).
- **Сохранение состояния**: позиция слова автосохраняется (каждые ~24 слова / 3 с,
  при паузе, сворачивании и выходе); после force-закрытия чтение продолжается с места
  остановки. Онбординг показывается один раз.

## Архитектура

```
src/
├── core/       # чистое ядро без UI: ReaderEngine, TextParser, Timeline, ORP,
│   │           # декодер кодировок, форматтеры, i18n-словари, модели
├── data/       # импортёры (TXT/PDF/EPUB/URL/HTML) + репозитории (KV/IndexedDB)
├── domain/     # агрегация статистики, use-cases
├── app/        # zustand-сторы (settings/library/reader/stats/app), навигация, AppRoot
├── features/   # экраны: onboarding, home, library, import_, reader, stats, settings
├── ui/         # UI-кит и тема (dark/light палитры)
├── services/   # haptics, OCR-движок (точка расширения)
└── storage/    # KV-драйверы: SQLite (native) / IndexedDB (web), один интерфейс
```

Ключевой принцип: **UI не содержит бизнес-логики**. `ReaderEngine` отвечает только за
тайминг и выдачу текущего слова; `TextParser`/`Timeline` — за нарезку и длительности;
репозитории — за хранение; сторы связывают их и хранят состояние.

### Производительность

- Длительности слов хранятся в безразмерных «юнитах»: смена скорости — O(1)
  (меняется один множитель), пересборка массива не нужна.
- Позиция ищется бинарным поиском по `Float64Array` — seek за O(log n) на книге
  в 500 000 слов.
- Список библиотеки не тянет тексты: метаданные и текст хранятся раздельно.
- Ридер рендерит ровно одно слово (три текст-сегмента prefix/pivot/suffix).

## Сборка релизов

```bash
npx eas build -p android   # или -p ios (требуется аккаунт EAS)
```

`app.json` уже настроен: тёмная тема по умолчанию, adaptive icon, разрешения камеры
(OCR), плагины expo-sqlite / expo-font / expo-localization / expo-camera /
expo-notifications.

## Подключение OCR (опционально)

По умолчанию камера честно сообщает, что движок распознавания не включён
(ML Kit требует dev-сборку). Чтобы включить:

```bash
npm install @react-native-ml-kit/text-recognition
```

и подставить реализацию `OcrEngine` в `src/services/ocr/OcrService.ts` — пример
в комментарии там же. Остальной код менять не нужно.
