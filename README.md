# RSVP Reading

<p align="center">
  <b>Читайте быстрее. Понимайте глубже.</b><br/>
  Кроссплатформенное приложение скоростного чтения (RSVP) для Android и iOS.
</p>

---

**RSVP Reading** — метод Rapid Serial Visual Presentation: слова появляются одно за другим в фиксированной точке экрана. Глазам не нужно двигаться по строке — скорость чтения вырастает в 2–4 раза без потери понимания.

## Возможности

### Чтение
- **RSVP-ридер** с точным таймингом: 100–1500 слов/мин, смена скорости на лету без пересчёта расписания
- **ORP (Optimal Recognition Point)** — опорная буква каждого слова всегда в одной и той же точке экрана, взгляд остаётся на месте
- Умные паузы: длинные слова, знаки препинания и концы абзацев получают больше времени автоматически
- Контекст строки: предыдущее и следующее слово видны по краям приглушённо — чтение выглядит осмысленным
- «Барабан»: свайп влево/вправо листает слова по ходу движения пальца, вертикальный свайп меняет размер шрифта (16–120 pt)
- Иммерсивный режим: тап по тексту скрывает весь интерфейс, авто-скрытие через 10 секунд
- Экран «Весь текст» — читайте как книгу и продолжайте RSVP с любого слова

### Библиотека и импорт
- **TXT / MD** (UTF-8 и CP1251), **PDF** (собственный парсер: Object Streams, FlateDecode, ToUnicode CMap), **EPUB**, **FB2** (FictionBook), **веб-страницы по URL**, **буфер обмена**, ручной ввод
- Чтение диапазонов: весь текст / страницы (для PDF — реальные) / фрагмент
- Автосохранение позиции: закройте приложение на слове 5000 — продолжите с него
- Статусы: не начато / читается / завершено

### Статистика и настройки
- Сессии чтения: слова, время, средняя и максимальная скорость, график по дням
- Фильтры: неделя / месяц / всё время; «лучшие результаты»
- 4 шрифта (Inter, Manrope, Literata, JetBrains Mono), размер 24–120 pt
- Круглая палитра любого цвета: текст, фон, опорная буква
- 6 тем интерфейса: Тёмная, Чёрная (OLED), Океан, Светлая, Сепия, Системная
- Языки: **Русский, Қазақша, English**
- Ежедневное напоминание о чтении (системное уведомление в 20:00)

## Приватность
Всё данные — тексты, прогресс, статистика — хранятся **только на устройстве** (SQLite / IndexedDB). Никаких серверов, аккаунтов и телеметрии. Интернет нужен только на момент импорта по URL.

## Установка

### Готовый APK
Скачайте [RSVP-Reading.apk из Releases](https://github.com/Qubera/rsvp-reading/releases/latest), откройте на Android-устройстве и разрешите установку из неизвестных источников.

### Из исходников (Android)
```bash
npm install
npx expo prebuild -p android
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

### iOS
Сборка требует macOS + Xcode:
```bash
npm install
npx expo prebuild -p ios
cd ios && pod install
# открыть *.xcworkspace в Xcode → Run
```
Либо облачная сборка через [EAS Build](https://expo.dev/eas) (конфигурация `eas.json` в репозитории):
```bash
npm i -g eas-cli && eas login
eas build -p ios
```

### Запуск в разработке
```bash
npm install
npm start          # Expo dev-сервер (Expo Go или эмулятор)
npm run web        # веб-версия
npm run typecheck  # проверка типов
npm test           # 53 unit-теста ядра
```

## Архитектура

```
src/
├── core/       # чистое ядро без UI
│   ├── reader/     ReaderEngine (unit-тайминг, O(1) смена скорости)
│   ├── text/       TextParser, Timeline, ORP, декодеры кодировок
│   ├── models/     типы документа, сессий, настроек
│   ├── i18n/       словари ru/kk/en
│   └── utils/
├── data/       # импортёры (TXT/PDF/EPUB/FB2/URL) + репозитории
├── domain/     # агрегация статистики
├── app/        # zustand-сторы, навигация, корень приложения
├── features/   # экраны: home, library, import_, reader, stats, settings, onboarding
├── ui/         # UI-кит и темы
├── services/   # haptics, OCR (точка расширения), напоминания
└── storage/    # KV-драйверы: SQLite (native) / IndexedDB (web)
```

**Принципы:** UI не содержит бизнес-логики. `ReaderEngine` отвечает только за тайминг и текущее слово; парсер и таймлайн — за нарезку и длительности; репозитории — за хранение; сторы связывают слои.

**Производительность:** длительности слов хранятся в безразмерных «юнитах» — смена скорости O(1), поиск позиции бинарный O(log n) даже на книге в 500 000 слов. Ридер рендерит одно слово тремя текст-сегментами (prefix/pivot/suffix).

## Тесты
53 unit-теста ядра: тайминг движка, парсер, ORP, декодер кодировок, импортёры (EPUB roundtrip, PDF с ToUnicode/ObjStm), агрегация статистики.
